# 📝 ToDo List

Sistema de gerenciamento de tarefas desenvolvido para praticar desenvolvimento Frontend com JavaScript puro e, futuramente, Backend e Banco de Dados.

Este projeto faz parte da minha evolução como desenvolvedor e está sendo construído em etapas, simulando o desenvolvimento de uma aplicação real.

## 🚀 Funcionalidades

### ✅ Implementadas

- Dashboard
- Cadastro de tarefas
- Validação dos campos do formulário
- Listagem dinâmica das tarefas
- Edição de tarefas através de Modal
- Exclusão de tarefas
- Organização por:
  - Nome
  - Categoria
  - Prioridade
  - Data limite
  - Status

## ▶️ Como executar

Clone o projeto:

```bash
git clone https://github.com/seuusuario/todolist.git
```

Entre na pasta:

```bash
cd todolist
```

Abra o arquivo:

```
index.html
```

ou utilize a extensão **Live Server** do VS Code.
